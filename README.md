# GitHub SDK for Zig

A client for the [GitHub REST API](https://docs.github.com/rest) in pure Zig, with no dependencies beyond the standard library. It covers all 813 paths in GitHub's OpenAPI description, with a struct for every schema.

## Generated by openapi2zig

The client in `src/client.zig`, `src/models.zig` and `src/runtime.zig` is generated by [**openapi2zig**](https://github.com/christianhelle/openapi2zig), an OpenAPI to Zig code generator, from GitHub's MIT-licensed [REST API description](https://github.com/github/rest-api-description). This release was generated with openapi2zig 0.6.2. To regenerate it, see [docs/REGENERATING.md](docs/REGENERATING.md).

## Install

Requires Zig 0.17.0 or later.

```bash
zig fetch --save git+https://github.com/christianhelle/github-sdk-for-zig#v0.1.0
```

Then add the module to your `build.zig`:

```zig
const github = b.dependency("github", .{
    .target = target,
    .optimize = optimize,
});
exe.root_module.addImport("github", github.module("github"));
```

## Quickstart

```zig
const std = @import("std");
const github = @import("github");

pub fn main(init: std.process.Init) !void {
    // An empty token means anonymous requests, limited to 60 per hour.
    const token = init.environ_map.get("GITHUB_TOKEN") orelse "";

    var client = github.init(init.gpa, init.io, token);
    defer client.deinit();

    var repository = try github.client.reposGet(&client, "christianhelle", "chlogr");
    defer repository.deinit();

    std.debug.print("{s} has {d} stars\n", .{
        repository.value().full_name,
        repository.value().stargazers_count,
    });
}
```

The [usage guide](docs/USAGE.md) covers authentication, error handling, pagination, request bodies and the limitations of the generated code.

The [examples](examples) are compiled in CI, and you can run them from a clone of this repository:

| [create_issue](examples/create_issue.zig) | Sending a JSON request body |

```bash
zig build run-get_repository -- christianhelle chlogr
```

## Development

```bash
zig build test
```

```bash
zig build check
```

```bash
zig build examples
```

`zig build check` compiles every generated operation. Zig normally skips code that nothing calls, so `zig build test` alone won't catch a broken operation.
