# Changelog

## 0.1.0

First release of GitHub SDK for Zig.

- GitHub REST API client generated by a build of [openapi2zig](https://github.com/christianhelle/openapi2zig) newer than 0.6.1 from GitHub's REST API description 1.1.4
- `github.init` helper that targets api.github.com
- Usage guide and compiled examples
