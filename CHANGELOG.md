# Changelog

## 0.1.0

First release.

- GitHub REST API client generated by [openapi2zig](https://github.com/christianhelle/openapi2zig) 0.6.1 from GitHub's REST API description 1.1.4
- `github.init` helper that targets api.github.com
- Usage guide and compiled examples
- A generator bug affects 38 operations, listed under [Known limitations](docs/USAGE.md#known-limitations)
- Requests without a body that get a 204 response can take about 30 seconds, described under [Known limitations](docs/USAGE.md#known-limitations)
