# Regenerating the client

`src/client.zig`, `src/models.zig` and `src/runtime.zig` are generated by [openapi2zig](https://github.com/christianhelle/openapi2zig) from `docs/openapi.json`. Don't edit them by hand, because regenerating overwrites them. `src/root.zig` and `src/compile_check.zig` are hand-written and aren't touched.

The current client was generated with openapi2zig 0.6.2, from version 1.1.4 of GitHub's REST API description. Each generated file records its generator version and commit in its header.

Use version 0.6.2 or newer. Version 0.6.1 puts some path arguments in the wrong order and stalls on 204 responses.

## Install openapi2zig

Linux/macOS:

```bash
curl -fsSL https://christianhelle.com/openapi2zig/install | bash
```

Windows (PowerShell Core):

```powershell
irm https://christianhelle.com/openapi2zig/install.ps1 | iex
```

## Refresh the OpenAPI description (optional)

GitHub publishes the description in [github/rest-api-description](https://github.com/github/rest-api-description). This repository uses the `api.github.com` bundle:

```bash
curl -fsSL https://raw.githubusercontent.com/github/rest-api-description/main/descriptions/api.github.com/api.github.com.json -o docs/openapi.json
```

## Generate

Run this from the `docs` directory:

```bash
openapi2zig generate -i openapi.json -o ../src/ --multiple-files
```

The generator skips a file when only its header would change. Delete `src/client.zig`, `src/models.zig` and `src/runtime.zig` first if you want every header to show the new version.

## After generating

1. Run `zig build test`, `zig build check` and `zig build examples`.
2. Update [Known limitations](USAGE.md#known-limitations) if anything changed.
3. Update the generator and description versions in this file, the README and the changelog.
